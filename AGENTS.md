# Instructions pour toute IA — dépôt TECHNOFASCISME-Infographie-interactive

Infographie interactive statique (HTML, CSS, JavaScript), publiée par GitHub Pages à l'adresse https://tristan.pro/TECHNOFASCISME-Infographie-interactive/ : tout ce qui est poussé sur `main` est en ligne aussitôt.
- `index.html` : page d'accueil ; `pages/` : les sous-pages (démocraties, figures, idéologies, infrastructure, origines) ; `css/`, `js/` : styles et scripts.
- Pas de build : on modifie les fichiers directement. Tester en local (ouvrir `index.html`) avant de pousser.
